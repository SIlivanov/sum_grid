  
# Sigma-Grid

Отказоустойчивая распределенная клиент-серверная система на C++17 для параллельного вычисления математических рядов с использованием контрольных точек.

## Особенности
- **Master-Worker / Producer-Consumer**: Сервер распределяет задачи между пулом подключенных воркеров.
- **Отказоустойчивость (Fault Tolerance):** При `Ctrl+C` (graceful shutdown) воркер сохраняет накопленный результат, шлет контрольную точку на сервер, а сервер перенаправляет недосчитанный остаток другому клиенту.

- **Утилизация CPU**: Каждый воркер задействует собственный пул потоков (`ThreadPool`) на количество физических ядер CPU (`hardware_concurrency`).
- **Сетевой уровень**: Разработан бинарный протокол на базе библиотеки `Asio`.
- **Тестирование**: Модульные тесты с использованием фреймворка `Google Test` .

## Сборка проекта

### Требования
- Компилятор с поддержкой C++17 (GCC 9+, Clang 10+, MSVC 2019+)
- CMake 3.16+
- Git

### Инструкция по сборке

```bash
# Клонирование репозитория
git clone https://github.com/SIlivanov/sum_grid.git
cd sum_grid

# Загружаем библиотеку Asio в папку libs
git clone --depth 1 https://github.com/chriskohlhoff/asio.git libs/asio

# Конфигурация и компиляция через CMake
mkdir build && cd build
cmake ..
cmake --build .
```

### Запуск тестов
```bash
cd build
./tests/run_tests
```
### Запуск сервера
Находясь в папке build
```bash
./server/server 8080
```
### Запуск воркеров
```bash
./client/client --worker 127.0.0.1 8080
```

### Отправление задачи от клиента заказчика
```bash
./client/client --request 1 3000000000 127.0.0.1 8080
```
